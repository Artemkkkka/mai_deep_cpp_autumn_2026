# mai_deep_cpp_autumn_2026
# C++ Programming — Магистратура, 1 курс, 1 семестр

Репозиторий с домашними работами по дисциплине **«Программирование на C++»** за первый семестр первого курса магистратуры.

## 📋 О дисциплине

Курс посвящён изучению современного C++ (стандарт C++20).

## 📚 Список работ

| №  | Тема                       | Ключевые концепции                              | Статус |
|----|----------------------------|-------------------------------------------------|--------|
| 01 | Аллокатор                  | Линейный аллокатор`new/delete`                  | ⏳     |
| 02 | Парсер                     | Callback-функции (`std::function`, лямбды), парсинг строк | ⏳     |

> Легенда: ✅ — выполнено, ⏳ — в процессе, ❌ — не выполнено

## 🛠️ Требования

- **Компилятор:** GCC 16.1.0 (MSYS2 UCRT64)
- **Стандарт C++:** C++20
- **Система сборки:** GNU Make 4.4.1
- **Флаги компиляции:** `-std=c++20 -Wall -Werror -Wextra`
- **ОС:** Windows 10 (MSYS2 / MINGW64, UCRT64 environment)
- **Тесты:** GoogleTest (опционально)

## 🚀 Сборка и запуск

### Сборка конкретной домашней работы

    cd 01
    make
    make test
    make clean

## 📖 Использование

Каждая работа содержит собственный `README.md` с:

- постановкой задачи;
- описанием алгоритма/архитектуры;

## 🎯 Цели курса

- Освоить современный синтаксис и идиомы C++.
- Научиться проектировать классы.
- Разобраться в управлении памятью.
- Освоить STL и обобщённое программирование.
- Познакомиться с многопоточностью и конкурентностью.
- Приобрести навыки работы с системой сборки Make и тестированием.
